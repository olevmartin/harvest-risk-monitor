# Harvest Risk Monitor

Build a single-page B2B supply chain dashboard. Use a clean slate background with minimalist enterprise UI. Include a large map placeholder. Create a prominent red alert panel saying: 'CRITICAL RISK: Upcoming 10-day heatwave will reduce pea yield by 30% in Southwest Finland. Deficit: 450 tons.' Add a Recharts line chart showing historical yield vs predicted drop. Add a primary call-to-action button: 'Find alternative suppliers'
